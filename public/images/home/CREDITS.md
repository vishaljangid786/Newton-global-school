# Home page sample photography

This folder mixes two kinds of image, and the table below says which is which.

**School's own** rows are Newton Global School's real photographs, supplied by the
school. They carry no third-party licence.

Every other row is **CC0 / public domain** placeholder stock retrieved via the
Openverse API — free for commercial use, no attribution required, and still
waiting to be replaced by real school photos. To swap one, drop the new file in
under the same name and dimensions and no page code needs to change.
